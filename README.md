# Política sem torcida

Páginas que organizam informação política com fonte primária, separando fato, interpretação e alegação, com o mesmo critério para todos os lados.

- [Ficha do 2º turno](https://politica-sem-torcida.github.io/)
- [Casos: Lula e Flávio](https://politica-sem-torcida.github.io/casos/)

As páginas são geradas por `publicar.mjs` a partir de arquivos de trabalho; o que está em `docs/` é o que vai ao ar.
